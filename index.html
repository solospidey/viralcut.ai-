04 YOUTUBE CONNECTION

Publish to your channel

Set up Google OAuth credentials to enable official YouTube uploads. The first upload will open Google's consent screen on the server machine.

  1. Create a Google Cloud project and enable YouTube Data API v3.
  2. Create an OAuth 2.0 Client ID (Desktop app).
  3. Download the JSON file and save it as client_secret.json in the project folder.
  4. Run ViralCut AI on your computer and approve the Google consent screen.

YouTube may apply daily upload quotas and channel eligibility restrictions. Scheduled uploads require this server to stay online.
